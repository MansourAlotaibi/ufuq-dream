# Provider and content release review — 2026-11-03

This free, nonprofit GitHub release contains no ads, subscriptions, private API keys, club artwork or redistributed personal video. Code licensing does not override service terms.

- **Open-Meteo**: https://open-meteo.com/en/terms permits free non-commercial private/nonprofit apps without ads/subscriptions, with published rate limits (10,000/day, 5,000/hour, 600/minute; monthly plan table also lists 300,000). Data are CC BY 4.0; adjacent Open-Meteo attribution and detailed credits remain. Active-only 30/60/180-minute refresh, cache and backoff do not promise unlimited access. Commercial use requires reviewing a paid plan. https://open-meteo.com/en/licence
- **TheSportsDB**: https://www.thesportsdb.com/api.php documents the public v1 identifier 123 without signup and a 30 requests/minute free limit. https://www.thesportsdb.com/docs_terms_of_use.php (updated 2026-09-17) permits official-endpoint content copying/modification subject to rights and prohibits app-store publication without paid subscription. This is a GitHub community release, not an app-store submission or commercial/unlimited-service claim. Only factual team names/IDs and normalized next-fixture fields are used, no logos/photos. Success is reused for an hour; retries are bounded, only a saved team while visible. Shared endpoint/provider limits and changing terms can affect availability. No provider endorsement or uptime guarantee.
- **AlAdhan**: https://aladhan.com/prayer-times-api and existing reviewed calendar endpoints. Source/city/timezone/method/school validation and rolling 30-day cache remain. Calculated schedules are not official mosque certification. No API key or silent switch to another calculation method. The existing prayer reference comparison is retained under docs/0.9.0; it is not a new physical accuracy certification.
- **Offline calculation**: Adhan Java 1.2.1, MIT; existing parameters unchanged.
- **Quran**: https://tanzil.net/docs/text_license — CC BY 3.0 with verbatim-copy/source-link/copyright conditions. The complete corpus copy matches the original Launcher asset hash. No Quran body edits, ellipsis, normalization or machine translation. Tanzil source/link is displayed beside the citation; full notice retained in corpus and app credits.
- **Hadith selections**: Arabic Wikisource, CC BY-SA 4.0; original revision links, attribution, text-selection notice and conventional/alternative numbering preserved in daily_reflection.json. Complete selected matn, not a claim of a full hadith collection/isnad. Text stays Arabic in English UI.
- **Fonts**: six unmodified OFL 1.1 files, per-file original source revisions, SHA-256 and license notices in assets/font-provenance.json. The original religious body and clock digits keep dedicated typography.
- **Photos**: all 13 original runtime/thumbnail hashes and per-image source/license/change records checked by tools/check_public_assets.py. CC BY/CC BY-SA assets are not relabeled MIT. Public screenshot adaptations preserve attribution and share-alike notices.

Private motion clips remain excluded until explicit redistribution permission covers APK/source distribution. Local import/playback is included; possession and private testing do not establish public media rights.

Public distribution can proceed as an accurately labeled GitHub release candidate with these features and limits. No app-store/commercial distribution or globally unlimited API rights are claimed. Re-review terms before a commercial fork or store submission.
