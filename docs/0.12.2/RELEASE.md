# Ufuq Dream 0.12.2-rc1

Compact outside-corner weather; unified full-width fixture/reading card with a conditional hairline separator and natural height. Empty sections disappear. Team headline/details have distinct hierarchy; weather glyphs use semantic restrained colors. Stale weather older than three hours is not presented as current. Original small prayer period vectors are decorative only and do not calculate times.

Automatic library checks replace the technical toggle. Both the saved and preview settings must enable reading; no request is admitted merely by staging reading on. The obsolete reading_updates key remains stored without affecting requests. Validated connectivity, visible-only scheduling, 15-day successful cadence, bounded retry/backoff, cancellation, signed verification and atomic offline fallback are unchanged. No new permission, background job, analytics or account.
