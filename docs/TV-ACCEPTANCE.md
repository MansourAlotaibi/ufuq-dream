# TV acceptance

Source baseline0.8.2 was accepted by its owner on Mi Box S1/API28. New video preview was observed using Amlogic AVC hardware decode for more than one source duration without a logged crash; the owner subsequently reported excellent screensaver operation. This is not certification of other TVs, overnight playback, invisible loop joints or sleep/wake reliability.

Before a public binary release, record device/model/API, APK hash/signature, exact pass/fail and whether each check is host or physical:

- All palettes and13 photos; readable clock/dates/greeting from3m; no clipped text at720p/1080p/4K and increased font scale.
- Arabic/Latin digits,12/24h,seconds,date visibility,long40-character mixed greeting, all9 positions.
- Every D-pad path;2/3/4/13-row dialogs; selected/disabled states, Back/focus restoration and TV keyboard.
- Preview immediate feedback, Save/Cancel, unsaved Back, Activity recreation and process restart.
- Fresh public install contains photos and no motion promise. Motion absent/unsupported/missing/corrupt gracefully uses photos/poster.
- Authorized local motion: correct speed, silent audio, loop boundary, rotation interval and fixed selection; no two decoders.
- Rapid start/stop, preview hidden, Dream exits immediately with remote, sleep/wake, timezone/day change.
- Long-run memory/CPU/temperature observation; record codec/compositor memory separately when available.
- No settings/data/launcher/storage changes outside the app. Respect device-specific debugging/adopted-storage conflicts.
