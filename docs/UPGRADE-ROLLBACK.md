# Upgrade and rollback / الترقية والرجوع

- Public package remains `com.ufuq.dream`. 0.8.2 is versionCode14; 0.8.3-rc1 is versionCode15. 0.9.0-rc1 is versionCode22; 0.10.0-rc1 is versionCode28. Clock grid choices migrate to Automatic/Left/Right, hidden preferences are retained, and current-language fonts remain independent. Preference schema/keys are preserved; Arabic/English now determines numerals. Night dimming remains opt-in. No old display modes were reintroduced.
- Accepted personal APK uses Android Debug certificate SHA-256 `4410e47d17424072462e54aaea741ed865afb474367f027c1c45f9e7e794e3d3`. This is a public certificate, not a secret.
- The public production release has a different certificate. Android correctly rejects an in-place update from the personal debug install. **Do not uninstall or clear data to bypass this on an existing TV.** The existing installation is untouched by publication. There is no automatic cross-certificate preference migration/export in this RC.
- A fresh user installs the production APK normally. Subsequent higher-versionCode releases signed with this same production key update in place and preserve app data/preferences (subject to Android/vendor behavior).
- Lower-version APK installation may be blocked by Android. A production-signed previous APK is required for any compatible rollback. The private 0.8.2 debug APK cannot roll back a production install in place. Never promise data-preserving downgrade across signatures or schema changes.
- Safest recovery is a forward fix with the same production key and a higher versionCode. Keep the prior source, APK, checksums and public certificate metadata. No downgrade command, uninstall or data clear is performed by this project.

لا تحتاج إلى استبدال نسختك المقبولة على Mi Box لاختبار نشر GitHub. لا تغيّر USB Debugging أو التخزين المتبنّى أو المشغّل. نسخة الإنتاج لا تستبدل نسخة الاختبار ذات التوقيع المختلف.

## 0.11 reading and occasions
0.11.0-rc1 production versionCode32 updates prior production versions using the same certificate. Separate legacy remembrance plus Quran/Hadith choices merge into the unified combination; previous fixed occasions remain selected, hidden remains hidden. Custom name/date are local staged preferences. Older builds may reject/ignore modes4–7 and need reading reselection if a downgrade is otherwise supported. Do not uninstall/clear data to force a rollback; preserve source/APK and prefer a forward fix. No private debug TV installation is replaced during public publication.

## 0.12 reviewed library
0.12.0-rc1 production versionCode35 preserves public production signing and preferences. The private matching dev2 versionCode34 uses the existing separate debug key; publication does not install the production APK on that TV. Library updates default OFF without overwriting other choices. Bundled pack version2 retains all original nine entries and adds twelve approved entries. Content cache and update state are separate from user settings. Verified newer cached content cannot be replaced by an older network pack. A compiled trusted fallback remains available if the cache is corrupt. Do not clear data or force a downgrade; keep earlier artifacts and prefer a same-key higher-code forward fix.
